# Mahasiswa Frontend (React + Vite)

Antarmuka web responsif berbasis React.js dan Axios untuk menampilkan, menambahkan, dan menghapus data mahasiswa yang terhubung dengan Backend Express API.

## Fitur Utama
- Menampilkan daftar mahasiswa secara dinamis dari MySQL
- Menambahkan data mahasiswa baru dengan validasi form
- Menghapus data mahasiswa dengan dialog konfirmasi
- Tampilan responsif untuk perangkat desktop maupun mobile

## Cara Instalasi & Menjalankan
1. Pastikan server Backend sudah berjalan di `http://localhost:5000`.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Jalankan aplikasi frontend:
   ```bash
   npm run dev
   ```
4. Buka browser dan akses `http://localhost:5173`.
